## 本项目的安全边界

本项目是一个**离线运行的单页 3D 演示**，没有服务端、账号与数据库。以下性质界定了它的安全边界。

### 无后端

没有服务端进程、没有接口、没有登录，也不接收任何上传。所有计算都在浏览器里完成，因此不存在「服务端被攻破」这一类风险。

### 运行时不联网

页面不使用 `fetch` / `XMLHttpRequest` / `WebSocket` / `EventSource`，不加载外部字体、图片或脚本。Three.js 以官方构建放在 `assets/vendor/`，纹理与 VSOP87 数据由 `scripts/` 下的脚本生成后随仓库分发。

`scripts/check-offline.js` 会在提交前扫描这些 API 与外部资源引用，防止无意中引入联网代码。

### 本地存储

只写一个 `localStorage` 键（音效开关，见 `assets/js/audio.js`），不写 Cookie，不做任何跨站跟踪或统计上报。`file://` 下浏览器拒绝存储时会静默退化为默认值。

### 输入面

页面接受的输入只有 URL 里的 `#seed=` 种子与界面上的画质档位、显示开关，全部只影响本地渲染，不参与 HTML 拼接。教学数据由 `scripts/check-teach-data.js` 校验契约，避免把未经验证的内容渲染出来。

### 第三方文件

`assets/vendor/` 中是从上游项目取得的官方构建，`assets/js/textures/`、`assets/js/textures-manifest.js`、`assets/js/vsop87.js` 为生成物。**不要手改这些文件**；需要更新时重新运行对应脚本并核对来源与许可（见 `NOTICE`）。

### 不属于本项目的安全边界

以下情况不在维护范围内：

- 用 `python -m http.server` 等工具把整个目录挂到公网——任何人都能下载全部文件，包括你尚未公开的改动
- 浏览器扩展、系统代理、宿主机的安全问题
- 自行修改后引入的远程请求、统计代码或第三方脚本
- 旧副本、二手打包版本与截图中的演示数据

### Reporting a vulnerability

**Do not open a public issue for a security problem.** A public issue exposes the details to everyone.

Report privately to the maintainer:

- Email: [412110785@qq.com](mailto:412110785@qq.com)
- GitHub private advisory: the repository's **Security** tab → **Report a vulnerability**

Please include:

1. The affected file and line (or commit)
2. Steps to reproduce: browser, how the page was opened (`file://` or a local server), quality tier, and the `#seed=` value in the URL
3. Impact and possible consequences
4. Any mitigation you already know of

**Expected response time**: acknowledgement within 3 business days, initial assessment and a fix plan within 7. Once fixed, the patch lands on `main` and the issue is disclosed publicly unless you ask for a longer embargo.

### Security boundary

This project is an **offline single-page 3D demo** with no server, accounts or database. The following properties define its boundary.

**No backend.** There is no server process, no API, no login and no upload. Everything runs in the browser, so there is no server to compromise.

**No network at runtime.** The page never uses `fetch` / `XMLHttpRequest` / `WebSocket` / `EventSource`, and never loads external fonts, images or scripts. Three.js ships as the official build under `assets/vendor/`; textures and VSOP87 data are generated by the scripts in `scripts/` and committed with the source.

`scripts/check-offline.js` scans for those APIs and external references before you commit, so networking code cannot slip in unnoticed.

**Local storage.** Exactly one `localStorage` key is written (the sound toggle, see `assets/js/audio.js`). No cookies, no cross-site tracking, no analytics. Under `file://`, browsers that block storage make it fall back to the default silently.

**Input surface.** The only inputs are the `#seed=` value in the URL plus the quality tier and display toggles in the UI. They affect local rendering only and are never concatenated into HTML. Teaching data is validated by `scripts/check-teach-data.js` so unverified content is not rendered.

**Third-party files.** `assets/vendor/` holds official upstream builds; `assets/js/textures/`, `assets/js/textures-manifest.js` and `assets/js/vsop87.js` are generated. **Do not hand-edit them** — regenerate with the corresponding script and verify the source and licence (see `NOTICE`).

**Out of scope.** The following are not covered:

- serving the whole folder publicly (e.g. `python -m http.server` on a public interface), which exposes every file including unpublished changes
- browser extensions, system proxies or host-level issues
- remote requests, analytics or third-party scripts you add yourself
- old copies, repackaged builds, and demo data visible in screenshots
